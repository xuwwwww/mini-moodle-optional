# Mini Moodle Optional

第三組的 AI agent 方法工作區。主題沿用 Mini Moodle，本輪做到需求分析。

使用者已採用第一輪的五項建議，並於 2026-11-06 確認需求規格與 UML。

| 檔案 | 內容 |
| --- | --- |
| `method.md` | 角色、工作循環與人工審閱關卡 |
| `requirements-draft.md` | 同一產品的需求草稿與待決問題 |
| `requirements.md` | 第一輪決定後的需求規格 |
| `uml/system.md` | 類別圖與課碼加入流程圖 |
| `runs/01-plan-and-trace.md` | 第一次 agent 計畫、輸入與執行紀錄 |
| `runs/02-revision.md` | 第一輪審閱後的修訂紀錄 |
| `runs/03-review-and-preview.md` | 第二輪審閱與本機預覽紀錄 |
| `review-01.md` | 第一輪的五項決定 |
| `review-02.md` | 需求規格與 UML 審閱結果 |
| `review-03.md` | 報告、簡報與 GitHub 發布決定 |
| `ai-usage-log.md` | AI 使用與人工決定紀錄 |
| `evidence.md` | 人工決定、AI 錯誤和時間紀錄 |
| `dialogue-excerpts.md` | 人工決定與後續工作摘錄 |
| `report/optional-section.md` | Optional 報告文字稿與比較來源 |
| `slides/optional-content.md` | 三頁簡報文字稿 |
| `deliverables/` | Word 報告與 PowerPoint 簡報 |

資料來源：課程的 `Midterm_Project_2026 (1).pdf`、10 月 23 日的 LINE 功能討論，以及 Agile 組的 MM-1、MM-2、MM-9、MM-3、MM-4 使用者故事。

共同範圍是登入、建課、課碼加入、公告與留言。審閱決定見 `review-01.md`。
